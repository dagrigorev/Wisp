## Unicode character data (uucode)

`src/vt/unicode/props_table.inc` is generated by
[`tools/gen_unicode_props.py`](tools/gen_unicode_props.py) from the Unicode
Character Database files shipped with
[uucode](https://github.com/jacobsandlund/uucode), the package Ghostty uses to
build the same table. The generator follows uucode's property derivations and
the width rules in Ghostty's `src/build/uucode_config.zig`, and lays the result
out as the 3-stage lookup table of Ghostty's `src/unicode/lut.zig`.
`src/vt/unicode/grapheme.hpp` also transliterates uucode's grapheme break
state machine.

uucode is distributed under the MIT License:

> Copyright (c) 2026 Jacob Sandlund

The Unicode Character Database itself is distributed by Unicode, Inc. under the
Unicode License (https://www.unicode.org/license.txt). No UCD file is
redistributed in this repository; only the derived table is, which the license
permits.

## X11 color names (rgb.txt)

`src/terminal/res/x11_rgb_data.inc` embeds `rgb.txt` from the X.Org
project (https://gitlab.freedesktop.org/xorg/app/rgb), by way of Ghostty,
which ships the same file as `src/terminal/res/rgb.txt`. It is used by
`color.hpp` to resolve X11 color names such as "ForestGreen". The file is
distributed under the MIT/X11 license.

## Zig standard library

`src/zigstd/` transliterates parts of the Zig standard library (0.16.0) that
Ghostty depends on for observable behavior: `std.hash.Wyhash` (hash map
placement) and `std.Random` with `Xoshiro256`/`SplitMix64` (the seeded
generators upstream's tests draw from). https://codeberg.org/ziglang/zig
